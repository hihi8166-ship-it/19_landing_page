# 어나드 범어 메인 페이지

참고: https://www.anadd.co.kr/apt/

`index.html`을 브라우저 또는 VS Code Live Server로 열면 됩니다. 별도 설치나 빌드가 필요하지 않습니다.

- `css/`: 원본 레이아웃, 반응형 스타일과 애니메이션
- `style.css`: 추가 스타일 수정
- `js/`: 메뉴, 스크롤, 슬라이드 동작
- `img/`, `popup/`, `font/`, `assets/`: 로컬 이미지, 글꼴과 라이브러리

메인 페이지를 로컬로 구현했습니다. 하위 메뉴는 원본 사이트의 상세 페이지로 연결됩니다. Vimeo 영상과 외부 문서는 인터넷 연결이 필요하며, 영상 재생은 원본 서비스의 접근 정책에 영향을 받을 수 있습니다. 원본의 분석 및 광고 추적 코드는 제거했습니다.

브라우저 실행 승인이 거절되어 실제 렌더링과 인터랙션은 검증하지 못했습니다.
